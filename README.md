# android-product-list

App Android simples de **listagem de produtos** — exercício de RecyclerView com Material Components.

## Objetivo

Praticar listagem de itens em `RecyclerView` com adapter, view holder e layouts Material.

## Tecnologias

- Kotlin
- RecyclerView, AppCompat, Material, ConstraintLayout
- Gradle 7.4 / compileSdk 33 (minSdk 21)

## Pré-requisitos

- **JDK 11**
- Android SDK Platform **33**

## Como rodar

```bash
echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties   # macOS
./gradlew assembleDebug
```

Ou abrir no Android Studio e executar `MainActivity`.
